# 세 갈래 철로 단축 검수

2026-10-26. 선택 뒤 계속 이어지던 철로를 줄이고 다음 맵 입구로 연결했습니다. 기존 오른쪽 위 HUD·운동 목표·얼굴 서버 연결은 유지합니다. GitHub 업로드와 실제 서버 배포는 하지 않았습니다.

## 변경한 흐름

| 항목 | 이전 | 현재 |
| --- | --- | --- |
| 갈림길 구조 | 5청크·120m | 2청크·48m |
| 선택 가능 구간 | 회차 내 108~144m | 96~120m |
| 완전히 갈라진 뒤 추가 직선 | 48m | 0m |
| 선택 후 다음 맵 입구까지 | 72m | 24m |
| 입구 / 본 구간 시작 | 216m / 240m | 144m / 168m |
| 좌우 철로 간격 | 8.8m | 6.6m |

프로젝트 수레 기본 속도 6m/s 기준으로 선택 후 입구까지 약 12초에서 4초로 줄었습니다. 실제 시간은 설정 속도에 따라 달라집니다. 회차 전체 길이는 48청크로 유지하고, 목적지 구간을 앞당겼습니다. 세 방향의 목적지는 회차마다 섞이며 확정 전에는 미리 생성하지 않습니다.

갈라지는 곡선은 각 연결점에서 속도·가속도가 0이 되는 보간을 사용합니다. 좁아진 세 터널과 다음 맵 연결로의 폭·천장 높이를 맞추고, 선택하지 않은 출구만 막습니다. 연결로는 세 레인을 사용할 폭을 확보했습니다. 확정 후에는 선택한 철로를 유지하고 하차 시 좌우 조작을 복구합니다.

## 검증

- Unity 6000.3.10f1 EditMode **115/115**, PlayMode **37/37**, Windows x64 빌드 성공. 컴파일 오류 0개.
- 세 방향의 실제 철로/수레 좌표, 바닥·벽·천장, 선택하지 않은 출구 차단, 세 목적지의 3레인 바닥과 높이 연결을 확인했습니다.
- 확정 직전의 선택, 같은 프레임의 캐릭터/수레 위치, 하차 후 조작 복구, 100청크 재사용 시 풀 증가 없음과 기존 메뉴/운동/얼굴 연결 회귀를 검사했습니다.
- 실제 Windows EXE에서 세 방향 곡선·목적지 입구를 캡처하고, 맵 이동·캐릭터 연출·결과까지 경로 검수를 완료했습니다. 종료 코드 0.
- 기본 EXE 스모크(로딩·미끄러짐·120청크·충돌·결과·재시작) 통과, 종료 코드 0.
