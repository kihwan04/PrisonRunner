# 플레이 HUD 정리와 성능 검증

기준일: 2026-10-26. 통합 메뉴/얼굴 서버를 유지하면서 플레이 HUD를 정리하고 관련 반복 작업을 줄였습니다. Git 커밋·업로드와 실제 외부 서버 배포는 하지 않았습니다.

## 적용한 최적화

- `RunHudModel`은 Update에서 프레임당 한 번 갱신하고 OnGUI는 저장한 표시값을 사용합니다. 거리계 외곽선용 10회 텍스트 그리기는 작은 거리 라벨 1회로 바꿨습니다.
- 장애물 안내 검색을 0.1초 간격으로 제한합니다. 차선/수레 전환은 바로 검색하고, 일시정지/결과에서는 검색하지 않습니다. 순회는 인덱스를 사용해 인터페이스 열거자 생성을 피합니다.
- 칼로리·코인·아이템 초 표시는 표시값이 달라질 때만 문자열을 생성합니다. 거리 문자열은 GUIContent 하나를 재사용하며 거리별 문자열을 사전에 계속 쌓지 않습니다.
- 장식 HUD는 Repaint에만 그립니다. 일시정지 버튼은 입력 이벤트를 계속 처리합니다. 일시정지에서는 플레이 HUD 전체를 그리지 않습니다.
- F3가 꺼져 있으면 ProfilerRecorder 수집을 멈춥니다. 켜져 있을 때는 StringBuilder/GUIContent를 재사용하고 표시 문자열이 바뀔 때만 글자 영역을 다시 계산합니다.

## 같은 PC의 전후 성능

NVIDIA GeForce GTX 1060 3GB, Direct3D 11, 1280×720, 키보드에서 측정했습니다. 갈림길·광산·감옥·동물원 4개 구간에 대해 화질별 2초 준비 후 7초씩 측정했습니다. 표의 FPS는 4개 구간 평균이며 p95는 각 구간 p95 중 가장 큰 값입니다.

| 프리셋 | 수정 전 FPS | 수정 후 FPS | 전/후 최대 구간 p95(ms) |
| --- | ---: | ---: | ---: |
| 보통 · 60fps 상한 | 59.82 | 59.76 | 17.05 / 17.04 |
| 높음 · 60fps 상한 | 59.78 | 59.83 | 17.07 / 17.04 |
| 저사양 · 30fps 상한 | 29.94 | 29.95 | 33.73 / 33.73 |

프레임 상한 근처에서 기존 성능을 유지했습니다. 이 차이를 최대 처리량 향상이나 유의한 FPS 개선으로 해석하지 않습니다. 이번 최적화의 직접 확인 범위는 HUD의 반복 검색·문자열·그리기와 계측 작업 감소입니다. [수정 전 측정](../previews/HudPolish20261026/before-performance.json), [수정 후 측정](../previews/HudPolish20261026/after-performance.json).

실물 웹캠 추론 부하·다른 GPU·장시간 메모리 안정성·스피커는 별도 확인이 필요합니다. 자동 측정 세션에서는 오디오 장치 초기화 경고가 나서 소리 출력 검증에서 제외했습니다. 기존 그림자 아틀라스 자동 축소 및 개발 빌드 종료 메모리 정리 진단은 남아 있습니다. PostgreSQL/Docker/외부 HTTPS는 이번 HUD 작업에서 변경하거나 재검증하지 않았습니다.

## 실행·전달

현재 실행은 루트 `StartGame.cmd`, 새 Windows 클라이언트와 PostgreSQL 서버 배포 ZIP은 루트 `Deliverables/2026-10-26/HudPolish/`를 사용합니다. 이전 전달물은 보존합니다. 공개 ZIP에는 개인 얼굴 데이터·DB·토큰·설치별 서버 주소를 넣지 않습니다.

재검증 도구는 `Tools/QA/verify_unity_merge.ps1`(선택적 ProjectPath/ReportDirectory)와 `Tools/QA/verify_hud_player.ps1`입니다. 실제 서버/장비 준비는 [다음 계획](../DEVELOPMENT_PLAN.md)을 따릅니다.

추가 배치 요청으로 거리·최고 기록·운동 목표를 오른쪽 위로 모았습니다. 이 위치 조정은 `Builds/QA/HudPlacement20261026/`의 새 Windows 빌드·16개 화면·스모크로 확인했습니다. 위 성능 표와 150개 테스트는 앞선 HUD 정리 시점 결과이며 위치 조정 후 전체 성능/테스트를 다시 측정한 결과로 표기하지 않습니다.

배치 조정 검수에서는 16개 화면 생성 후 자동 캡처 실행본 종료 중 네이티브 Windows 콜백 오류(종료 코드 -1073740771)가 반복됐습니다. 원인과 수정은 확인하지 못했습니다. 관련 없는 입력 변경 시도는 되돌렸고, 요청한 HUD 배치 변경을 유지합니다. 캡처 종료 오류를 정상 종료로 처리하지 않으며 `Builds/QA/HudPlacement20261026/UiCapture-crash.log`에 진단을 보존합니다. 기본 플레이 스모크 결과와 구분합니다.
