# 화면별 기획서 V13 검수

2026년 10월 5일. V12의 화면과 그림 구성을 유지하면서 문장을 자연스럽게 다듬고 거리 배치를 미정으로 정리했다.

## 생성 및 수정 파일

- 생성: `무한옥_화면별_게임기획서_V13.docx`, `Tools/AssetPipeline/refine_screen_plan.py`, 이 검수 기록.
- 수정: `Tools/AssetPipeline/render_screen_plan.py`, `Tools/AssetPipeline/verify_screen_plan.py`, `AGENTS.md`.
- 내부 검수 자료: `document-qa/V13/document-audit.json` 및 `document-qa/V13/final`의 렌더 결과.

## 반영 내용

- 반복적인 설명 표제와 구현 보고식 표현을 줄이고, 화면에서 일어나는 일과 사용자가 할 동작을 연결된 문장으로 정리했다.
- 맵 길이, 높이, 장애물 위치·간격, 거리별 가속 기준과 공식, 고정 속도 수치를 제거했다. 아직 확정되지 않은 배치는 실제 플레이를 보면서 정한다고 명시했다.
- 플레이가 이어질수록 빨라지는 흐름, 감속 뒤 회복, 일시정지와 재시작 기준은 유지했다. 속도 표는 수치 대신 진행 상황별 변화와 의도로 정리했다.
- 장애물 모습과 몸동작·키보드·실패 조건, 맵 순서, 사진 20장과 회피 설명도 10장은 유지했다.
- 바닥글과 쪽번호가 없는 상태를 유지했다. 기존 화면 사진의 HUD는 참고 촬영본이며 확정 거리 배치의 근거가 아니다.

## 검수 결과

- V12 원본은 SHA-256 비교로 보존을 확인했다. 최종 문서에서 본문 XML과 문서 속성을 제외한 모든 패키지 파트가 원본과 바이트 단위로 동일하다.
- 본문과 표에 고정 미터 거리·속도 수치가 없고, 거리 미정 안내와 필요한 동작이 있는지 확인했다.
- 바닥글 참조 0개, 모든 바닥글 파트의 텍스트·필드·그림·표 부재를 확인했다.
- 최종 렌더의 1~29쪽을 모두 원본 크기로 열어 확인했다. 한글, 사진, 설명도와 표에 잘림이나 겹침이 없고 각 장이 한 쪽에 들어간다.
- 구조 검증: `SCREEN_PLAN_VERIFICATION_PASS: V13 / 29 rendered pages / 20 photos / 10 diagrams / 4 tables / 25 gallery images`.
- 게임 코드와 설정은 이번 작업에서 수정하지 않았다. Unity 컴파일은 수행하지 않았으며 문서 작성·렌더·검증 오류는 없다.

## 남은 결정 사항

맵 길이와 장애물 간격, 시작·최대 속도와 가속 간격은 아직 미정이다. 실제 몸동작으로 연속 회피 여유와 안내 시점을 확인한 뒤 배치를 확정하고 화면을 다시 촬영한다.
