# 화면별 기획서 V12 검수

2026년 10월 5일. V11 기획서에서 모든 바닥글을 제거하고 장애물의 모습과 회피 동작을 추가했다.

## 결과물과 변경 파일
- 생성한 문서: `무한옥_화면별_게임기획서_V12.docx`. 29페이지, 기존 화면 사진 20장, 회피 설명도 10장, 표 4개.
- 생성: `Tools/AssetPipeline/update_obstacle_plan.py`, 이 검수 기록, `document-qa/V12/obstacle-diagrams`의 설명도 10개.
- 수정: `Tools/AssetPipeline/render_screen_plan.py`, `Tools/AssetPipeline/verify_screen_plan.py`, `AGENTS.md`.
- V11 원본은 SHA-256 비교로 보존을 확인했다. 원본 사진과 스타일 등 관련 없는 패키지 파트도 바이트 비교로 보존을 확인했다.

## 반영한 내용
- 기본·첫 페이지·짝수 페이지의 바닥글 내용을 비우고 모든 바닥글 참조를 제거했다. 쪽번호, 버전 문구, 표·그림·필드가 바닥글에 남아 있지 않다.
- 낮은 상자, 파이프, 하이니 계단, 입구 슬라이드 문, 감옥 차단 문, 수레 붕괴 철로, 바나나, 물웅덩이의 형태와 회피 동작을 각각 표시했다.
- 차단벽과 레이저는 기존 판정 표의 보조 유형으로 설명하고 현재 10개 본편 경로에 사용하지 않는다고 명시했다.
- 각 설명에 등장 위치, 식별 방법, 몸동작, 키보드 입력, 통과 시점과 실패 결과를 넣었다. 본문 22장의 맵 표에도 필요한 키와 회피 방향을 반영했다.
- 설명도는 실제 게임 촬영 사진과 구분해 회피 설명도로 표기했다. 새 그림은 설명을 위한 도식이다.

## 검수 결과
- 패키지의 바닥글 참조 0개와 모든 바닥글 파트의 텍스트·필드·그림·표 부재를 검증했다.
- 최종 렌더 `document-qa/V12/final`의 29페이지를 모두 원본 크기로 열어 확인했다. 한글, 사진 비율, 그림, 표, 페이지 끝과 바닥글 제거 상태에 잘림·겹침이 없다.
- 첫 렌더에서 맵 표가 다음 페이지로 넘어간 것을 수정했다. 최종 맵 표는 22장 한 페이지에 있고 회피 설명은 25~29장에 각 2개씩 배치한다.
- 구조 검증 결과: `SCREEN_PLAN_VERIFICATION_PASS: V12 / 29 rendered pages / 20 photos / 10 diagrams / 4 tables / 25 gallery images`.
- 문서 작업으로 게임 C# 코드를 변경하지 않았으며 새 Unity 컴파일은 수행하지 않았다. 문서 작성과 렌더 오류는 최종 검증에서 없다.

## 남은 문제와 다음 작업
문서의 시각·구조 오류는 발견되지 않았다. 기존 사진은 V10 참고 자료다. 새 운동 행과 속도 HUD의 실제 플레이 화면 촬영, 실제 웹캠 운동으로 회피 난이도 검수가 다음 작업이다.
