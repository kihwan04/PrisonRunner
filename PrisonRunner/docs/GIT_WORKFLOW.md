# Git 작업 흐름

대상 저장소는 개인 계정의 `kihwan04/PrisonRunner`입니다. 외부 원본 `leewono/muhanok`에는 업로드하지 않습니다. 2026-10-29 최신 요청은 검증한 통합 소스를 develop에 병합하는 범위입니다. 새 릴리스·태그·서버 배포는 승인하지 않았습니다. 현재 저장소 기본 브랜치는 `develop`입니다.

## 브랜치와 통합

| 브랜치 | 역할 |
| --- | --- |
| `main` | 검증을 마친 발표 가능한 안정 버전 |
| `develop` | 기능 통합 |
| `feature/<기능명>` | 기능 단위 개발 |

새 작업 전에 현재 브랜치, staged/unstaged 변경과 진행 중인 병합을 확인합니다. 기존 작업과 병합 상태를 보존하고 기능별로 검증한 뒤 승인받은 범위에서 `develop`에 통합합니다. 공개 태그·릴리스·배포는 별도 요청이 있을 때만 진행합니다. `main`과 다른 작업 브랜치는 별도 통합 요청 없이 바꾸지 않습니다. 이 문서 자체가 병합·푸시 실행을 허가하는 것은 아닙니다.

## 커밋과 파일

메시지는 `<유형>(<범위>): <변경 목적>` 형식으로 목적 하나를 표현합니다. `feat`, `fix`, `chore`, `docs`, `refactor`, `test`를 사용합니다. 브랜치와 메시지에 작성 도구·생성 주체·자동 서명을 넣지 않습니다.

Unity 소스와 대응 `.meta`를 함께 관리합니다. Library/Temp/Logs, 로컬 빌드·전달 ZIP, Python 런타임·환경, 개인 얼굴 DB/사진/토큰, `.env`, 설치별 `identity-server.json`, 재배포 제한이 있는 Mixamo 원본은 Git에서 제외합니다. 출처·라이선스·고정 모델 manifest는 보존합니다.

문서를 이동하면 상대 링크와 생성/패키징 도구의 파일 경로를 함께 수정합니다. 현재 안내만 `docs/`에 두고, 대체된 이전 버전은 보관하지 않고 삭제합니다(Git 기록에 남음). 이전 검증 결과와 이번 변경에서 실제 수행한 검증을 구분합니다.
