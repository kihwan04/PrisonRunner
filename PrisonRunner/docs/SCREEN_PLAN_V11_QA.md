# 화면별 기획서 V11 검수

2026년 10월 5일. 사용자의 맵별 점프·슬라이드와 점진 가속 요청을 기존 화면별 기획서에 반영했다.

## 생성 및 수정 파일
- 결과물: `무한옥_화면별_게임기획서_V11.docx` (24페이지, 사진 20장, 표 4개).
- 생성: `Tools/AssetPipeline/update_screen_plan.py`, 이 검수 기록.
- 수정: `Tools/AssetPipeline/render_screen_plan.py`, `Tools/AssetPipeline/verify_screen_plan.py`, `AGENTS.md`.
- V10 원본 파일은 SHA-256 비교로 변경되지 않았음을 확인했다. 사진·스타일·관계 등 관련 없는 DOCX 패키지 파트는 원본 바이트를 유지한다.

## 반영 내용
- 도보 맵 점프·슬라이드 행과 첫 광산 점프 생략, 계단 점프·하이니·문 아래 슬라이드, 감옥 문 레인 회피.
- 수레의 좌우 기울이기와 숙이기, 점프·하이니 예외.
- 실제 누적 이동 거리에 따라 9m/s에서 120m당 1m/s씩 연속 가속, 960m부터 최대 17m/s.
- 감속과 회복, 속도 HUD, 동작 안내, 슬라이드 중 점프 우선, 일시정지와 재시작 기준.

## 문서 검수 결과
- 최종 렌더: `document-qa/V11/final`. 모든 24페이지 PNG를 원본 크기로 열어 한글, 사진 비율, 표, 페이지 끝과 겹침을 검수했다.
- 쪽번호와 V11 표기는 1~24까지 연속이며, 확대 이미지와 PDF 텍스트로 확인했다. 전체 페이지 이미지 표시에서 일부 글자가 빠져 보였으나 실제 파일에는 정상 출력되어 있다.
- Word 구조 및 PDF 페이지 수, 맵·속도·조작 표, 핵심 문구, 기존 화면 갤러리 이미지 경로 검증을 통과했다.
- 이 작업은 문서 수정이며 C# 코드를 변경하지 않았다. 문서에 기록한 EditMode 49개와 PlayMode 23개 통과, Windows 빌드 및 실행 검증은 직전 기능 구현의 결과다.

## 자료의 한계와 다음 작업
- 사진 20장은 V10 참고 화면으로 명시했다. 새 운동 행과 속도 HUD의 최신 실행 사진은 아직 재촬영하지 않았다.
- 실제 웹캠 운동으로 최고 속도와 안내 시간을 검수하고 최신 플레이 화면을 촬영하는 것이 다음 작업이다.
