# 다음 개발 계획

기준일: 2026-10-26. 현재 구현과 확인된 테스트는 [진행 상태](PROGRESS.md)에 있습니다. 초기 MVP 계획은 [이전 계획](archive/history/BEFORE_2026_10_26_DEVELOPMENT_PLAN.md)으로 보관합니다.

| 순서 | 할 일 | 완료 기준 |
| --- | --- | --- |
| 1 | 중앙 서버와 도메인 준비 | Docker/Compose가 동작하는 서버와 연결 가능한 DNS 확보 |
| 2 | PostgreSQL/Docker·HTTPS 배포 | 비밀번호 파일 준비, DB/API health 정상, 외부 HTTPS에서 storage=postgres 확인 |
| 3 | 두 게임 PC 연결 | 같은 서버에서 얼굴 등록→다른 PC 로그인→개인 기록 확인→삭제 검증 |
| 4 | 실제 웹캠 조작 검수 | 전신·상체·손 메뉴·재보정·카메라 끊김을 실제 장치에서 확인 |
| 5 | 현장 성능·사용감 검수 | 웹캠 추론을 켠 채 화질별 측정, 장시간 반복, 스피커 소리 확인 |
| 6 | 다음 공개 배포 | 개인 저장소 develop과 릴리스에 검증된 소스·실행 파일을 게시 |

현재는 서버/도메인 없이 배포 파일과 새 Windows 클라이언트만 준비했습니다. 사용자 요청으로 [개인 저장소 게시](https://github.com/kihwan04/PrisonRunner/releases/tag/v2026.10.26)를 재개했으며 실제 서버 배포는 별도로 준비합니다.

변경은 기능 단위로 진행합니다. Unity·패키지 버전을 임의로 올리지 않고, 게임 규칙과 표현/외부 연결을 분리하며 기존 키보드 플레이를 유지합니다. 새로운 작업을 완료했다고 기록할 때는 실제로 수행한 검사와 남은 실물 확인을 구분합니다.
