# 성능 설정과 측정

기준일: 2026-10-26. 설정은 F1, 성능 표시는 F3으로 엽니다. 높음/보통 프리셋은 기본 60fps, 저사양은 30fps 상한을 사용합니다.

## 현재 적용 범위

- 화질 프리셋: 렌더 해상도, 그림자, SSAO, 표시 거리 조절.
- 반복 청크·장애물·동물·바나나 풀링, 갈림길 메시와 충돌 데이터 사전 생성/재사용.
- 원거리 소품·보이지 않는 조명과 선택하지 않은 터널 뒤쪽 표시 제한.
- 확장 경로는 구조를 앞쪽 96m까지 준비하고 안개·카메라 표시 거리를 맞춤. `Render.LookAhead` 기본값은 일반 경로용이므로 확장 경로의 실제 값과 구분.
- full/lite 포즈 모델 선택. 추적 중에는 직전 영역을 이어 사용하고 놓쳤을 때 검출기를 재실행.

## 기록된 측정

2026-10-25, GTX 1060 3GB / Direct3D 11 / 1280×720에서 측정했습니다. 각 조합 2초 준비 후 7초 측정했으며 **실제 웹캠 추론 부하는 제외**했습니다.

| 화질 | 갈림길 | 광산 | 감옥 | 동물원 |
| --- | ---: | ---: | ---: | ---: |
| 보통 | 59.7 | 59.4 | 59.8 | 59.8 |
| 높음 | 59.8 | 59.8 | 59.7 | 59.8 |
| 저사양 | 30.0 | 30.0 | 30.0 | 30.0 |

단위는 FPS입니다. 프레임 상한에 가까운 결과이며 최대 처리 성능이나 최적화 향상률을 뜻하지 않습니다. 근거는 [당시 보고서](reports/LOCAL_COMPLETION_2026_10_25.md)에 있습니다. 원시 측정값(`docs/previews/Polish20261025/review.json`)은 저장소에서 삭제했고 Git 기록에 남아 있습니다.

2026-10-26 HUD 정리 후 같은 GPU·해상도에서 12개 맵/화질 조합을 다시 측정했습니다. 보통 59.76fps, 높음 59.83fps, 저사양 29.95fps로 기존 상한 근처 성능을 유지했습니다. 장애물 검색은 0.1초 간격으로 제한하고 고정값 HUD 모델의 관리 메모리 할당을 0바이트로 확인했습니다. F3를 끄면 계측도 멈춥니다. 조건·p95·전후 값은 [HUD 보고서](reports/HUD_POLISH_2026_10_26.md)를 확인하세요. 실물 웹캠 추론은 제외했습니다.
