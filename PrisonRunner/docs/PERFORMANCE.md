# 성능 설정과 측정

기준일: 2026-10-26. 설정은 F1, 성능 표시는 F3으로 엽니다. 높음/보통 프리셋은 기본 60fps, 저사양은 30fps 상한을 사용합니다.

## 현재 적용 범위

- 화질 프리셋: 렌더 해상도, 그림자, SSAO, 표시 거리 조절.
- 반복 청크·장애물·동물·바나나 풀링, 갈림길 메시와 충돌 데이터 사전 생성/재사용.
- 원거리 소품·보이지 않는 조명과 선택하지 않은 터널 뒤쪽 표시 제한.
- 확장 경로는 구조를 앞쪽 96m까지 준비하고 안개·카메라 표시 거리를 맞춤. `Render.LookAhead` 기본값은 일반 경로용이므로 확장 경로의 실제 값과 구분.
- full/lite 포즈 모델 선택. 추적 중에는 직전 영역을 이어 사용하고 놓쳤을 때 검출기를 재실행.

## 성능 기록의 범위

이전 GTX 1060/720p 키보드 측정은 보통·높음 약60fps, 저사양 약30fps 상한 근처였으며 과거 원시값은 Git 기록에서 확인합니다. 실제 웹캠 추론은 제외한 결과입니다. 현재 통합 검사 결과는 [진행 상태](PROGRESS.md)를 확인하세요.

이번 미사용 리소스 정리는 저장소 크기를 줄이는 작업입니다. 게임에서 이미 제외되던 원본을 지웠으므로 FPS·실행 파일 크기가 개선됐다고 주장하지 않습니다.

## 다음 측정

같은 PC·해상도·맵 구간에서 화질별로 평균 FPS, 프레임 지연과 순간 끊김을 기록합니다. 실제 웹캠 추론을 켠 상태도 별도로 측정하고 재검출·청크 재사용·갈림길 진입 시점을 확인합니다. 노트북/다른 GPU 성능과 장시간 메모리 안정성은 별도 검수가 필요합니다.

UI 요소명은 [설정 UI](SETTINGS_UI.md)에 있습니다.

## 로컬 자동 화질 조절

선택 화질을 상한으로 렌더 스케일·그림자·SSAO·소품 거리를 조절하고, 높은 완화 단계에서는 포즈 추론 상한을 30→20회/초로 줄입니다. 모델·카메라를 재시작하거나 저장 설정을 바꾸지 않습니다. 모든 PC의 FPS를 보장하지 않으며 이번 PR 통합에서 새 성능 실측을 한 것으로 해석하지 않습니다.
