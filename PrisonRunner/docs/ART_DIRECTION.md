# 아트 작업 기준

기준일: 2026-10-26. Mongscape는 귀여운 원숭이 캐릭터와 감옥·광산의 묵직한 환경, 밝은 동물원 구간이 대비되는 Stylized 3D 러너입니다.

## 가독성과 연결

- 장애물과 안전한 차선을 먼저 읽을 수 있게 합니다. 완전 차단 차선, 점프·숙이기·하이니 장애물의 형태를 구분합니다.
- 수레 갈림길에서 실제 경로의 바닥·벽·천장과 카메라 이동을 맞춥니다. 임시 안내 문자로 공간의 빈 부분을 가리지 않습니다.
- 반복 청크의 입구·출구 높이, 바닥 면과 장식 타일의 겹침을 확인합니다. 풀 재사용 뒤에도 원래 상태로 돌아와야 합니다.
- 본편 1인칭과 수레/잡힘 연출에서 실루엣과 동작이 읽혀야 합니다. 로그인 얼굴 사진은 머리 관절을 따라갑니다.

## 현재 리소스와 교체

자체 Blender Humanoid 캐릭터·환경·동작, 게임에 포함된 Mixamo 동작, Kenney CC0 리소스와 생성 재질을 사용합니다. 실제 사용·후보·미임포트 상품을 구분합니다. 에셋 후보와 교체 지점은 [에셋 목록](ASSET_CATALOG.md), 재배포 조건은 [외부 리소스 안내](../THIRD_PARTY_NOTICES.md)에 있습니다.

Visual Mesh와 Collider를 분리하고 모델 교체가 게임 규칙을 바꾸지 않도록 합니다. 새 리소스는 크기·피벗·재질·콜라이더·라이선스를 확인한 뒤 사용합니다. Mixamo 원본 FBX를 공개 ZIP/소스에 넣지 않습니다.

## 검수

URP 화질 프리셋별로 어두운 광산, 감옥, 야외, 갈림길을 확인합니다. 빠른 이동과 반복 타일에서 깜빡임, 카메라 관통, 보이지 않는 바닥/벽, 그림자와 프레임 급락을 점검합니다. 게임 기능과 가독성을 장식보다 우선합니다.
