# 통합 메뉴와 플레이어 데이터

`lilohdong/muhanok-test`의 기본 main 브랜치 `b2215ef`를 기존 Mongscape 소스에 통합한 화면입니다. 기존 얼굴 로그인·칼로리 목표·갈림길·경찰 연출·PostgreSQL 연결을 유지합니다.

## 화면 흐름

```text
타이틀 → 메인 메뉴
          ├ 게임 시작 → 처음이면 PC 프로필 → 탈출 준비 → 로딩 → 플레이
          ├ 거리 랭킹(전체/오늘)
          ├ 코인 상점
          ├ PC 프로필
          ├ 얼굴 로그인/등록/삭제
          ├ 설정
          └ 종료
플레이 → 일시정지: 계속 / 설정 / 메인으로(기록 없이 종료)
플레이 → 결과: 거리 랭킹·칼로리·동작별 기록·최고 콤보 → 다시 / 메인으로
```

준비 화면에서 플레이 방식과 칼로리 목표를 선택합니다. 키보드에서는 목표 입력을 비활성화하고 운동량을 적립하지 않는다고 안내합니다. 얼굴 로그인은 메인 메뉴와 준비 화면에서 엽니다. 원격 서버 주소 설정은 [서버 안내](../Services/Identity/README_DOCKER.md)를 따릅니다. 얼굴이 없어도 키보드·몸동작으로 플레이할 수 있습니다.

화면은 나무·금색 팔레트와 Black Han Sans 제목 글꼴을 사용합니다. 손 가리키기/유지 선택을 메뉴·상점·랭킹 버튼에 연결했습니다. 플레이 HUD는 오른쪽 위에 거리·최고 기록·운동 모드의 현재/목표 칼로리를 모으고, 그 옆에 일시정지를 표시합니다. 코인은 왼쪽 위에 표시합니다. 활성 아이템만 작은 타이머를 표시합니다. 큰 중앙 거리·상시 속도·구간 바·반복 조작 설명·별도 얼굴 사진은 제거했습니다.

하단 안내는 한 번에 하나만 표시합니다. 인식 복구 → 가까운 장애물 → 갈림길 선택 → 경찰 → 잠깐의 콤보/구간 전환 순서로 선택합니다. 전신·상체 모드에서는 우측 하단에 웹캠 화면(영상과 골격, 약 200×150)을 항상 표시하고, 설정 → 표시 → 플레이 중 웹캠 화면으로 끌 수 있습니다. 키보드 모드에서는 표시하지 않습니다. 잠깐의 포즈 누락은 무시하고 0.75초 이상 인식이 끊기면 복구 안내를 띄우고 웹캠 화면을 상태 표시가 있는 복구 화면(236×174)으로 키웁니다. 상세 거리·최고 기록·기준 속도·구간·칼로리는 일시정지에서, 동작별 기록은 결과에서 확인합니다. 키보드 결과에는 계산하지 않은 칼로리 목표/동작별 0값을 나열하지 않습니다.

## 데이터 저장 범위

| 저장 위치 | 내용 |
| --- | --- |
| 게임 PC `Player/profile.json` | PC의 이름·몸무게·기본 방식·목표 설정 |
| 게임 PC `Player/wallet.json` | 코인 지갑·상점 해금 |
| 게임 PC `Player/records.json` | 거리 기준 최대 500개 기록과 누적 통계 |
| 연결된 얼굴 서버 PostgreSQL | 얼굴 프로필·세션·프로필별 개인 운동 기록 |

PC JSON은 Unity의 `Application.persistentDataPath/Player` 아래에 있습니다. 상점 지갑과 메뉴의 거리 랭킹을 여러 PC에 자동 동기화하는 기능은 포함하지 않습니다. 얼굴 로그인 중에는 서버 이름을 표시하고, PC 프로필의 기본 이름을 서버 이름으로 덮어쓰지 않습니다. 서버 이름은 이 화면에서 변경하지 않습니다.

기존 `Exhibition/progress.json`과 `ranking-*.json`은 새 Player 파일이 없을 때 한 번 읽어 코인·해금·거리 기록을 이전합니다. 원본을 수정/삭제하지 않습니다. 예전 순위에는 칼로리 값이 없으므로 이전 통계에 임의로 추가하지 않습니다. 실제 사용자 데이터로 이전을 실행한 검증이 아니라 임시 파일을 사용한 검증입니다.

## 개발자/전시 모드

타이틀·메뉴에서 **Ctrl+Shift+F12**로 전환합니다. Windows 관리자나 서버 DB 관리자 권한과는 별도인 게임 운영 옵션입니다.

| 항목 | 일반 | 개발자/전시 |
| --- | --- | --- |
| 이름 | 저장된 PC 프로필 또는 로그인한 얼굴 | 준비 화면에서 판마다 입력 |
| 아이템 | 상점에서 해금 | 모두 사용 |
| 코인 | PC 지갑에 적립 | 지갑 적립 없음 |
| 랭킹 메뉴 | 전체 탭 | 오늘 탭 |
| 결과 버튼 | 다시 / 메인으로 | 다시 / 다음 플레이어 |
| Ctrl+F10 | 비활성 | 오늘 PC 기록 초기화 |

다음 플레이어로 넘어갈 때 얼굴 로그아웃과 캐릭터 사진 해제를 함께 처리합니다.

## 코드와 검수

`HUDPresenter`가 MenuPage를 전환하고, `Overlay/`가 메뉴·상점·프로필·랭킹·작은 거리계를 그립니다. `RunHudModel`이 프레임당 한 번 상태를 갱신하고 장애물 검색을 0.1초 간격으로 제한합니다(차선/수레 전환은 즉시). 화면 장식은 Repaint에서만 그립니다. `PlayerProgressStore`가 PC JSON을, `LocalProfileClient`가 얼굴 API를 담당합니다.

자동 검수는 개발 빌드에서 아래 플래그를 명시할 때만 실행됩니다. 실제 프로필과 카메라 대신 별도 폴더/합성 데이터를 사용합니다.

```text
Mongscape.exe --muhanok-uicapture --mongscape-tests --muhanok-out <캡처 폴더> --muhanok-data <임시 데이터 폴더>
```

검증 범위와 출처 커밋은 [통합 보고서](reports/MUHANOK_TEST_MERGE_2026_10_26.md)에 있습니다.

이후 HUD 정리와 성능 측정은 [HUD 검수 보고서](reports/HUD_POLISH_2026_10_26.md)를 확인하세요. UI 캡처의 Workout/Tracking Synthetic 화면은 합성 상태이며 실물 웹캠 검증과 구분합니다.

세 갈래 철로는 회차 내 96~120m에서 선택하고 144m부터 다음 맵 입구로 연결됩니다. 갈림길은 48m이며, 확정 후 긴 직선 구간을 제거했습니다. [경로 검수](reports/FORK_SHORT_2026_10_26.md).
