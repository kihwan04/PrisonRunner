# 무한옥 V5 · 경로, 로딩, 선택 몸무게

사용자 요청: 광산 → 계단 → 감옥 복도(문이 바닥까지 닫힘) → 동물원 사육장. 두 번째 첨부 이미지는 로딩 화면에 사용한다. 무료 에셋만 사용하는 기존 선택을 유지한다.

## 실제 경로

출현 순서는 `0,1,2,3,7,4,5,6,11,12`로 반복된다. 0~3은 광산/산업 시설 입구, 7은 계단, 4~6은 감옥 복도, 11~12는 사육장이다. 기존 세탁실/주방/정비 프리팹은 보존하며 이번 경로에는 출현하지 않는다.

- 기존 24m 청크, X=-2.2/0/+2.2 레인, 풀링을 유지한다.
- 계단에서 3m 올라가고 감옥은 같은 3m 높이에 이어진다. 사육장 진입의 완만한 경사에서 원래 높이로 내려와 다음 광산으로 연결된다.
- 감옥 차단문은 18m 앞에서 닫히기 시작해 8m 앞에서 바닥까지 닫힌다. 한 장애물 행에 하나의 문만 활성화해 나머지 두 레인으로 피할 수 있다. 지나간 문은 풀에서 재사용할 때 열린 상태로 초기화한다.
- 광산 암벽은 Blender에서 불규칙한 다면체 바위로 다시 제작했다. 주변광을 낮추고 랜턴 범위를 조정해 빛/그림자 대비를 높였다.
- 사육장에 포장석, 반짝이는 물웅덩이, 풀, 낮은 랜턴, 통나무·상자·바나나 껍질을 추가했다. 기린/코끼리는 자체 정적 모델에 작은 호흡/회전 움직임을 적용하며 골격 동물 애니메이션은 아니다.

## 시작과 로딩

타이틀을 클릭하면 몸무게 선택 입력 화면을 연다. 10~350kg의 숫자를 입력하거나 입력 없이 시작할 수 있다. 몸무게는 메모리에만 보관하며 파일/PlayerPrefs/외부 서비스에 저장하지 않는다.

시작하기 → 사용자 제공 로딩 이미지 → 8초 인트로 → 1인칭 본편. 준비 진행률은 입력/세션 초기화, 청크 풀 배치, 인트로 초기화 단계를 반영한다. 다운로드 진행률이 아니다. 장면은 다시 로드하지 않는다. 원본 이미지의 장식 진행 막대 위에 실제 준비 막대를 그린다.

HUD는 코인/거리/구간/추격과 일시정지 버튼을 표시한다. 몸무게를 입력한 경우에만 예상 칼로리 카드와 결과 값을 표시한다. 일시정지 중에는 게임 진행과 계산을 멈춘다. 16:9와 안전 영역을 유지한다.

## 칼로리 추정

`kcal = MET × 3.5 × 몸무게(kg) ÷ 200 × 인식된 활동 시간(분)`.

- [2024 Adult Compendium](https://pacompendium.com/wp-content/uploads/2024/03/1_2024-adult-compendium_1_2024.pdf)의 활동 코드 22240: 전신 동작을 사용하는 중간 강도 게임, 4 MET를 기본 가정으로 쓴다.
- [연구 논문의 MET 정의/계산](https://pmc.ncbi.nlm.nih.gov/articles/PMC1784117/)을 참고한다. 실제 호흡/심박 측정값이 아니라 이 게임에 적용한 추정 모델이다.
- 인식된 LEFT/RIGHT/JUMP/CROUCH/HIGH_KNEE 몸동작이 있고 Pose가 Connected인 Running 시간만 누적한다. IDLE/CENTER, 키보드만 사용, 인식 끊김, 로딩/인트로/일시정지/결과 시간은 제외한다.
- 활동 시간 안의 휴식 대사까지 포함한 gross kcal다. 모션별 강도를 실측하거나 게임 거리/속도를 실제 달리기 거리로 간주하지 않는다. 개인별 실제 강도와 차이가 있다.
- 예: 70kg, 4 MET 몸동작 1분 = 약 4.9 kcal. Retry는 누적 시간과 칼로리를 초기화하며, 입력 없이 시작하면 몸무게도 제거한다.

## 지정 에셋 확인

- [Police Officer - Proto Series / BitGem](https://assetstore.unity.com/packages/3d/characters/police-officer-proto-series-107256): 무료, rigged, 자체 애니메이션 없음, Mixamo/Mecanim 호환 설명. 받기 버튼에서 Unity 로그인 화면으로 이동했다. 파일 확보 전에는 현재 자체 경찰 모델을 사용한다.
- [Cartoon Monkeys](https://assetstore.unity.com/packages/3d/characters/cartoon-monkeys-108270): 확인 당시 $5.50. 무료만 사용한다는 사용자 선택으로 구매하지 않았다. 현재 자체 Blender 원숭이를 유지한다.
- Asset Store 상품이 아직 적용되지 않았는데 적용했다고 표시하지 않는다. 로그인/약관 승인 또는 사용자가 이미 보유한 원본이 필요하다.

## 수정 지점

`RouteSurface`, `ChunkSpawner`, `MuhanokMapChunk`: 경로/문 재사용.
`DescendingGate`, `AmbientAnimal`: 런타임 표현.
`WorkoutEstimate`: UnityEngine 없는 칼로리 모델.
`GameBootstrap`, `HUDPresenter.Start`: 몸무게/로딩/일시정지 연결.
`MuhanokArtUpgrade.Gates`, `.Zoo`, `.Maps`: 아트 제작과 장면 참조.
`References/Blender/MuhanokModules.blend`: 새 암벽/환경 원본.
`Unity/Assets/Game/Authoring/ProBuilder`: 기존 편집용 맵 원본 유지.

참고 이미지의 캐릭터 형태/표정/영화적 조명과 현재 실제 렌더의 차이는 남는다. 사용자 제공 로딩 이미지는 실제 게임 모델 렌더와 구분하며, 검증은 실제 Player 캡처로 한다.
