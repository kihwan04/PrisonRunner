# 무한옥 (PrisonRunner)

Windows에서 키보드 또는 웹캠 몸동작으로 플레이하는 Unity 러너 게임입니다.

- **게임 다운로드:** [Windows 실행용 ZIP](https://github.com/kihwan04/PrisonRunner/releases/latest/download/Muhanok-Windows-x64.zip)
- **최신 기획서:** [화면별 게임기획서 V13](PrisonRunner/docs/무한옥_화면별_게임기획서_V13.docx)
- **실행 및 파일 안내:** [처음 읽기](PrisonRunner/START_HERE.md)
- **개발 소스 설명:** [프로젝트 README](PrisonRunner/README.md)

ZIP을 모두 압축 해제한 뒤 `StartGame.cmd`를 더블클릭하세요. 게임 화면에서 **게임 시작 → 입력 없이 시작**을 누르면 됩니다. 몸무게 입력은 선택 사항입니다. Unity나 Python 없이 키보드로 플레이할 수 있습니다.

소스 ZIP에는 Unity 편집용 프로젝트가 들어 있습니다. 바로 플레이하려면 위 **Windows 실행용 ZIP**을 받으세요. 게임 버전은 V10 아트 + 2026-10-05 운동·가속 기능, 기획서 최신 버전은 V13입니다.
